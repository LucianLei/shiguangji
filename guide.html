只需设置一次 · iPhone / iPad

让心意，顺利抵达。

创建一个名为「拾光机」的快捷指令。点击它打开网页；完成认可后，网页会复制数据，再次打开同一个快捷指令，由它发送文字和贴纸照片。

当前网页已实现数据交接。以下快捷指令需在你的 iPhone 上配置；本页不是一键安装链接。首次使用请先发给自己测试。

先了解这条路线

点击「拾光机」 → 打开网页 → 填写认可、编辑照片 → 预览 → 复制数据并打开快捷指令 → 确认发送。

照片在本机缩放、移除原文件元数据并合成贴纸，以 JPEG 的 Base64 文本和认可内容一起交接。网页不收集或保存提交记录，刷新会清除本次内容。剪贴板会被本次数据替换，也可能参与 Apple 通用剪贴板同步。

创建快捷指令「拾光机」

打开 iPhone 的「快捷指令」App，点「＋」，把名称改为 拾光机（名称须完全一致）。按顺序添加以下操作。不同 iOS 版本的操作名称可能略有不同。

  1. 添加「如果」，条件选 「快捷指令输入」没有任何值。在该分支内添加「URL」，内容为下面的网址，再添加「打开 URL」和「停止此快捷指令」。将「否则」留空，接着「结束如果」。 
    https://lucianlei.github.io/shiguangji/
  2. 添加「从输入中获取词典」，输入选择「快捷指令输入」，将结果设为变量 认可数据。注意：读取已传入的输入，不要再次读取剪贴板。
  3. 从 认可数据 「获取词典值」，键为 source。如果结果不是 shiguangji，添加「显示提醒」（内容：这不是有效的拾光机数据）并停止快捷指令。
  4. 再从 认可数据 取键 schemaVersion；如果结果不是 1，显示提醒并停止。取键 message，设变量 认可文字；如果没有值，显示提醒并停止。
  5. 添加「文本」，填最终接收人的 iMessage 手机号或 Apple ID 邮箱，设变量 收件人。先填你自己的号码测试。收件账号只在这一处修改，不放进网页或 GitHub 仓库。
  6. 从 认可数据 取键 imageBase64，设变量 照片编码。添加「如果 照片编码 有任何值」：添加「Base64 编码」操作，切换为「解码」，输入选 照片编码；再添加「从输入中获取图像」，输入选解码结果；将图像设为变量 贴纸照片。如果图像没有值，显示提醒并停止。结束如果。图片解码放在发送之前，避免解码失败却已发送文字。
  7. 添加「发送信息」，内容选择 认可文字，接收人选择 收件人。展开操作设置，初次测试保留「运行时显示」，确认内容后发送。
  8. 添加「如果 照片编码 有任何值」，再添加一次「发送信息」，内容选 贴纸照片，接收人选同一个 收件人。结束如果。这样接收人会收到一条认可文字，以及一条可选的贴纸照片。这里无需下载图片网址。
  9. 两步发送都结束后，可添加一个空白「文本」和「拷贝到剪贴板」，清空本次数据。最后添加「显示通知」提示已完成快捷指令；实际送达以「信息」App 为准。

保存后，可在快捷指令的菜单中选择「添加到主屏幕」，分发给同事时使用快捷指令的 iCloud 分享链接。务必检查分享副本中的收件人。

第一次试用，这样检查

  1. 点击手机上的「拾光机」，应打开本网页。
  2. 填入姓名、同事姓名、团队和认可内容，不加照片，预览后点击「复制数据并打开快捷指令」。确认四项内容完整出现在信息里。
  3. 再试一张照片：添加两个表情，拖动、调整大小并旋转，检查预览和收到的照片都保留贴纸位置。
  4. 用一张竖向照片再试一次，确认照片方向正确；在真实 iPhone 上检查 emoji 合成效果。
  5. 确认接收人已开通 iMessage，发送气泡为蓝色。快捷指令的「发送信息」由系统决定消息类型；未开通 iMessage 时可能使用短信或彩信。
  6. 测试通过后，再把快捷指令中的 收件人 改为最终账号，分享给同事。

没有自动跳转，怎么办？

已复制，但没有打开快捷指令：点预览里的「手动打开快捷指令」。名称必须为「拾光机」，且已安装在这台手机。

浏览器不允许复制：在预览下方长按数据框，全选并复制，再点「我已复制，打开快捷指令」。推荐从 Safari 打开，首次允许网页写入剪贴板及打开快捷指令。

需要备份：预览中可下载 JSON 数据。接收快捷指令也可从「文件」读取 JSON，再接到「从输入中获取词典」操作。JSON 含认可和照片，请妥善保存。

照片看起来没有发送：检查发送操作的输入是解码后的 贴纸照片，不要选择 照片编码。如果文字已发出，重试可能造成重复，请先查看「信息」App。

快捷指令显示剪贴板权限提示：这是 iOS 的权限机制，允许后再继续。网页上的交接提示不等于信息已送达。

交接字段

键内容
sender / colleague / team我的名字 / 对方名字 / 对方团队
recognition原始认可内容
message整理好的完整信息，可直接发送
hasImage是否包含照片（布尔值）
imageBase64贴纸合成 JPEG 的 Base64；无照片时为空
submissionId / createdAt本次预览标识 / UTC 时间

交接采用 Apple 官方支持的 shortcuts://run-shortcut?name=…&input=clipboard。查看 Apple 快捷指令 URL 说明。
